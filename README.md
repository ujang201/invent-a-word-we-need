One invented English word, defined in a single clear line.

> **showergument** (n.) — the argument you finally win in the shower, hours after losing it in real life.

The word is a blend of *shower* and *argument*: the comeback you only think of under hot water, once the conversation is already over. It names a gap English has no word for — everyone has won an argument too late, in the shower — and it is sayable, spellable and memorable.

## How it works

`main.ts` assembles the entry from its parts (the two morphemes, three definition clauses), checks the gate — 1–140 characters, a single line, not whitespace-only — and writes the finished line to `/output/entry.txt`. The program is fully deterministic: the same input always produces the same bytes.

```sh
node main.ts
```
